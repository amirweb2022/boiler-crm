## Limits and deployment work

- These checks do not deploy the code or verify the updated public application domain serving this revision. Liara container Chrome availability, runtime libraries, and the daily platform cron schedule still need deployment verification.
- Downloading Puppeteer's managed Chrome returned HTTP 403 in this environment. Installed Google Chrome successfully generated the tested PDFs through the automatic fallback.
- Real Kavenegar delivery and handset receipt were intentionally not tested. Successful mock delivery verifies application behavior and notification storage.
- PDF generation and downloads were exercised; precise placement of every editable field on each scanned certificate template still requires template-specific visual acceptance.
- No standalone ESLint configuration is checked in. Build, TypeScript, regression tests, and the Liara E2E runner are the reproducible checks used here.

The latest machine-readable results and browser screenshots are in the ignored `test-results/` directory. The runner exits with a failure code if any check fails or is blocked.
