# Issue triage labels

Use these default labels for GitHub issues in `amirweb2022/boiler-crm`:

| Label | Meaning |
| --- | --- |
| `needs-triage` | New issue awaiting review, scope, and ownership. |
| `needs-info` | More information is needed before the issue can move forward. |
| `ready-for-agent` | Scoped work an agent can pick up. |
| `ready-for-human` | Scoped work needing a human to pick it up. |
| `wontfix` | Reviewed issue that will not be addressed. Record the reason in the issue. |

Update the label when the issue's status changes. This list defines the default vocabulary; it does not create labels on GitHub.
